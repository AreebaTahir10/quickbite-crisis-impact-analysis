\# 🍔 QuickBite Crisis Impact Analysis Dashboard



\## 📌 Overview



This project presents an interactive \*\*Power BI dashboard\*\* built to analyze the impact of an operational crisis on \*\*QuickBite\*\*, a food delivery platform. The dashboard compares business performance across the \*\*Pre-Crisis\*\* and \*\*Crisis\*\* periods, providing insights into customer behavior, restaurant performance, operational efficiency, and revenue trends.



The project was developed under the guidance and supervision of my manager, with a focus on creating an executive-level dashboard that supports data-driven decision-making.



\---



\## 📊 Dashboard Highlights



\- 📈 Executive KPI Overview

\- 📦 Monthly Orders \& Revenue Analysis

\- ❌ Cancellation Trend Analysis

\- 🚚 Delivery SLA \& Average Delivery Time

\- 👥 Customer Loyalty \& Segmentation

\- 🍽️ Restaurant Order Decline Analysis

\- ⭐ Customer Rating \& Sentiment Analysis

\- 💰 Revenue Loss \& Average Order Value (AOV)

\- 🎯 Interactive Tooltips \& Cross-Filtering
